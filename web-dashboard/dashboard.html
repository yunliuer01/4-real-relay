💡 联动说明
• 按钮通过父网关 192.168.30.160 的 HTTP API 下发 CH1-CH4 通道控制指令
• 门锁 CH1：解锁 = 上拉继电器吸合，上锁 = 释放继电器断开
• 灯1/灯2 CH2/CH3：分别控制两个照明回路，可独立开关
• 空调 CH4：单独控制大功率设备，避免误操作照明回路
• 告警复位：仅清空前端告警展示，不影响平台侧实际告警记录
